Netherstone is a free desktop app for documents and drawings. Each document is a Markdown file in a folder on your computer, and you can sync it through your own GitHub account.

## Repositories

| Repository | About |
| --- | --- |
| [Netherstone](https://github.com/Netherstone-HQ/Netherstone) | The app, for Windows, macOS and Linux. Built with Tauri, React and Rust. GPL-3.0 |
| [nethermark](https://github.com/Netherstone-HQ/nethermark) | A small Markdown editor built on CodeMirror 6, and an alternative to EasyMDE. On npm as `@netherstone/nethermark`. MIT |
| [templates](https://github.com/Netherstone-HQ/templates) | Vaults to start from. New templates are welcome as pull requests |
| [homebrew-tap](https://github.com/Netherstone-HQ/homebrew-tap) | Install on macOS with `brew install --cask netherstone-hq/tap/netherstone` |
